# Vision and plan

## Vision

**Every first-year at uOttawa can reach any Library service in one tap, and knows what exists by the end of their first week.**

The Library already has what students need: gear, studios, rooms, librarians. The gap is discovery. First Chapter closes that gap without asking students for their data.

## Who it's for

A first-year in September who has a paper due, needs a camera for a project, and doesn't know a Library can help with either.

## Principles

1. Fewer steps than the website, always.
2. Start from the student's situation, not the org chart.
3. Private by default: no account, on the device.
4. Complement the Library's systems, never replace them.
5. Bilingual, because uOttawa is.

## Plan

| When | Goal | Work | Success looks like |
| --- | --- | --- | --- |
| **Today** | Win the demo | Running prototype, real data, pitch | Judges see one tap against 5 clicks |
| **Next 30 days** | Library says yes | Show librarians, correct the catalog, full French, accessibility pass | Library agrees to a pilot |
| **Winter term** | Small pilot | TestFlight with 50 first-years, live equipment availability if the Library can share it | Most finish the swipe deck; fewer "where do I…" questions |
| **September 2027** | Orientation launch | App Store, QR codes at service desks and Welcome Week | Half of testers use 3+ services by Reading Week |
| **Later** | Beyond one campus | Catalog as a config file so other Omni libraries can adopt it | A second library pilots it |

These targets are proposals, not measured results.

## How we'd measure it

- Taps and time to reach a service, compared with the website.
- Share of students using 3 or more services by Reading Week, from an opt-in survey.
- Repeat "where is it" questions at service desks, as reported by Library staff.

## Risks

| Risk | Response |
| --- | --- |
| Catalog goes stale | Library-owned JSON file, each entry links to its official page |
| Students won't install another app | Offer the catalog as a web version too; use QR codes at the point of need |
| On-device AI needs newer iPhones | Local search works on every supported device |
| Library has no API for availability | Link out to existing systems; no fake status |

## What we won't do

- Sell or share student data.
- Require a login for browsing.
- Replace librarians. The app sends hard questions to them.
