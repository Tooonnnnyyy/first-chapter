# First Chapter landing page

Open `index.html` directly in a browser. It is a standalone static page with embedded CSS and four JPEG screenshot placements; no external scripts, fonts or image downloads are needed. Navigation anchors and official Library links work without a local server (external destinations require internet).

The screenshots are real iOS Simulator captures from the November 4, 2026 prototype, reused from `../docs/pitch/raw/small0.jpg`, `small1.jpg`, and `small3.jpg`. They replace the earlier illustrated wireframes. They may not reflect later changes to the native app.

This page is separate from the interactive web app in `../web/`. Updating this file does not deploy a site.
