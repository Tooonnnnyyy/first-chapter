# Contributing

[English](docs/en/maintenance.md) · [Français](docs/fr/maintenance.md) · [简体中文](docs/zh-CN/maintenance.md)

Start with an existing issue or describe the student problem in a new one. Work on a branch, include the relevant checks, and open a pull request. Small changes with verified behavior are welcome.

Read [README](README.md) for setup, [CODE_OF_CONDUCT](CODE_OF_CONDUCT.md) for community expectations, and [SECURITY](SECURITY.md) to report a vulnerability privately.
