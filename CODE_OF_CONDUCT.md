# Community code of conduct

We welcome students, librarians, developers, designers and translators of all experience levels. English, French and Chinese contributions are welcome.

- Be respectful and specific when giving feedback. Critique the work, not the person.
- Do not harass, discriminate, threaten, impersonate or publish another person's private information.
- Credit sources and respect software licenses. Do not copy unlicensed third-party code or branding.
- Keep discussions relevant and accessible. Explain unfamiliar terms and provide text alternatives for visual information.
- Never request student passwords, academic records or other sensitive data in public issues.

Maintainers may edit or remove harmful content, restrict participation, or close discussions to protect the community. Enforcement should be proportionate and explained when doing so would not expose private information.

For a conduct concern, use the repository's private reporting channel when available; otherwise ask a maintainer for a private channel without posting the sensitive details publicly. GitHub's abuse reporting tools are also available. Retaliation against a good-faith report is not acceptable.
